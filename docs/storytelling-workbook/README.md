# Storytelling in Scientific Writing — online workbook

A fillable web version of the participant workbook, for participants who can't open the Word file.

- One self-contained file: `index.html`. No server, database, or login.
- Answers save automatically in each participant's own browser (localStorage). Nothing is sent anywhere.
- "Look back" panels show earlier answers inside later activities, with a button to add them to the current answer.
- **Save a copy** menu: print / save as PDF, download as .txt, download a backup file, and restore from a backup on another device.

## Publishing with GitHub Pages (free, public link)

1. In the repository on GitHub, open **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the branch that contains this folder and the **/docs** folder, then **Save**.
4. After a minute or two the workbook is live at
   `https://tmc2727.github.io/AI-MicroApp-Template/storytelling-workbook/`

The `index.html` file can also be uploaded to an LMS (e.g., Canvas Files) or emailed. It opens in any modern browser and works offline, apart from the web font.
